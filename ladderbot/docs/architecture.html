LadderBot · integration architecture

Not a new repo — a spine that runs through four existing ones.

LadderBot is Ms. Juanita's ladder-scored futures-options method translated into code. No standalone repo was created; each of the four working repos hosts the layer that naturally fits its purpose, and the layers compose at runtime through explicit protocol boundaries.

Why no new repo. The ladder methodology is a strategy, not a platform. It plugs into Bee_bot's existing TradingStrategy base class, borrows DATASOURCE's gxt/analytics conventions, adds an mastery_ladder_ml package next to Mastery's other Python modules, and lands its backtest surface inside WTTracker's backend-trading-service. Cross-repo composition happens through two protocol seams — option_context_provider and strategy.scorer — so each repo can be developed and tested in isolation.
