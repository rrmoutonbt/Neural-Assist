LadderBot · sprint 9 · first end-to-end run

The pipeline works. The 90 gate does not clear.

First actual run of the full LadderBot stack: ingest → label → train a calibrated GBDT → walk-forward validate → report. Four symbols, three years of synthetic multi-regime bars, 1,856 labeled samples. Results honest, not tuned.

Headline. With this feature set on synthetic data, the model never produces a calibrated probability ≥ 85. The transcript's 90-gate ships zero trades. 100% hit rate is reachable at gates 65–80, but on 4–40 trades over three years — too thin to be a live strategy. High hit rate did not equal profit: the losing trades hemorrhaged more than the winners banked, exposing a mismatch between the fixed-$225-target rule and the delta-linear P&L simulator's end-of-hold mark-to-market.

05What this run tells us

  • The stack works end-to-end. Ingest → label → train → walk-forward → JSON report + saved .joblib. Every seam we shipped in Sprints 1–8 executed, in order, without a human in the loop.
  • The classifier has weak signal (AUC 0.565). Non-random, but nowhere near what would be required to earn a calibrated 90 probability. A stronger feature set (real S/R clearance from Sprint 2's futures_features, cross-instrument correlation, IV term structure) is the next honest place to invest.
  • High hit rate ≠ profitable in this simulator. The delta-linear P&L model books mark-to-market at the end of a hold when the target isn't hit — so a 90% winner rate with a 30-point average loser and a 22.5-point winner still bleeds. Sprint 10 needs a true option mark-to-market that respects the "fixed $ target, no stop" rule from the transcript.
  • The 90 gate is a claim, not a demonstration. With the current feature set the model produces no probabilities above 85, so on this dataset the transcript's advertised gate ships zero trades. Neither confirms nor refutes the transcript — just shows what the current features can support.
  • Where the numbers came from. 3 years × 4 symbols × 252 bidays = 3,024 bars; 1,856 candidates after DTE/stride filters. Synthetic multi-regime data — not real market data. Every number here is honest about that provenance.
Reproducibility. Run python scripts/run_ladder_pipeline.py --data synthetic --years 3 --gate 60 from the WTTracker checkout. Outputs land in out/ladder_run/: ladder_model.joblib and report.json. Swap --data yfinance in an environment with outbound HTTPS to Yahoo Finance for real CL / NQ / ES / ZS continuous-contract bars.
